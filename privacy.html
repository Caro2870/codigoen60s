Privacy Policy

Last updated: October 28, 2026 · Applies to the desktop tool "Codigo en 60s Publisher"

1. Summary

Codigo en 60s Publisher ("the Tool") runs on its owner's own computer and posts the owner's videos to the owner's own TikTok account. It does not collect data from other people, has no user accounts of its own, and does not sell or share data.

2. Data the Tool handles

  • From TikTok (scope user.info.basic): the account's open ID, display name and avatar, used only to confirm which account is signed in.
  • Access and refresh tokens issued by TikTok, stored locally on the owner's computer so the Tool can post without signing in each time.
  • Creator info returned by the Content Posting API (for example allowed privacy levels and maximum video length), used only to choose valid posting options.
  • Local video files and captions chosen by the owner, which the Tool uploads to TikTok (scopes video.upload and video.publish).

3. Where data is stored

Everything stays on the owner's computer, except the videos and captions that are sent to TikTok to be published. The Tool has no server and no database in the cloud.

4. Sharing

Data is shared only with TikTok, as needed to publish the videos. Nothing is sold, rented, or used for advertising. TikTok's handling of data is described in the TikTok Privacy Policy.

5. Retention and deletion

Tokens are kept until the owner signs out of the Tool or revokes access. Revoking access in the TikTok app (Settings and privacy → Security → Manage app permissions) invalidates the tokens. Deleting the Tool's local folder removes all locally stored data.

6. Children

The Tool is not directed at children and is used only by its adult owner.

7. Changes

If this policy changes, the date at the top of this page is updated.
